# Contributing

Thanks for your interest in improving this project! Contributions of all sizes
are welcome — bug reports, fixes, docs, and ideas.

## How to contribute

1. **Open an issue first** for anything non-trivial, so we can agree on the approach
   before you invest time.
2. **Fork** the repo and create a branch from `main` (`fix/...` or `feat/...`).
3. Keep changes focused — one logical change per pull request.
4. Make sure the project still builds and runs locally.
5. Open a **pull request** describing _what_ changed and _why_.

## Development

```bash
npm install
# run the CLI / open mockup.html as described in the README
```

## Style

- Match the existing code style (ESLint/Prettier where configured).
- Clear, descriptive commit messages; small, reviewable commits.

## Code of Conduct

By participating, you agree to abide by the [Code of Conduct](CODE_OF_CONDUCT.md).
